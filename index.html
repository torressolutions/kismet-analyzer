Advanced filters & data quality

Exports use the complete filtered result set, not just the first 1,000 displayed rows. JSON retains normalized fields and raw Kismet records when available. MAC classification uses address bits only: locally administered does not prove randomization; similar addresses or shared names do not prove a shared physical device. Bluetooth advertisement details depend on what the import format actually preserves.

Times are shown in UTC. “First seen” is the earliest timestamp recorded for that device; “Last seen” is the latest. When multiple captures are merged, these span the available captures. A dash (–) means the imported source did not provide that field; it is not a measured zero. Rows tinted across the full width indicate a device seen in multiple capture files. A stronger tint indicates that GPS coordinates differ across those file records; this suggests observations at multiple locations, but is not a continuous travel track.
